# Contributions

This directory is the canonical record of upstream open-source work.

## Status model

- **Open** — submitted upstream and awaiting a final outcome.
- **Merged** — accepted upstream.
- **Closed** — closed, superseded, declined, or otherwise completed without merge.

Each record should answer: **what changed, why, where, how it was validated, and what happened upstream?**
