# Contributing to OSS Atlas

OSS Atlas is primarily a personal open-source engineering record, but useful corrections, suggestions, and improvements are welcome.

## What belongs here

- Accurate contribution records
- Technical research and architecture notes
- Reproducible experiments
- Case studies based on real upstream work
- Lessons learned from open-source collaboration

## Standards

Keep entries factual, link to the upstream source, distinguish merged work from open work, and avoid claiming tests or outcomes that were not actually verified.

For contribution records, prefer:
- upstream repository
- issue/PR URL
- current status
- concise technical summary
- validation performed
- maintainer feedback, when relevant

## Pull requests

Keep PRs focused, documented, and easy to review. Do not add fabricated contribution data, artificial activity, or unverifiable statistics.
