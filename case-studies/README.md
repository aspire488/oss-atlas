# OSS Case Studies

Deep dives are reserved for contributions that expose meaningful engineering reasoning, maintainer feedback, debugging, architecture, or reusable implementation patterns.

## Standard

Each case study answers:

1. What was the upstream problem?
2. What changed?
3. What evidence was produced?
4. What did maintainers/reviewers verify or challenge?
5. What changed after review?
6. What reusable lesson remains?

An open PR is never presented as merged.
